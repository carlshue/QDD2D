# QDD2D
Quadtree-based Dynamic Diffusion (2D)

## Project Overview

Quadtree-based Dynamic Diffusion is a research prototype exploring **quadtree-based adaptive diffusion models** for image generation.  
The main idea is to represent images hierarchically using quadtrees, allowing the diffusion model to focus computation on high-detail regions while reducing memory and processing cost in uniform areas.

This project is designed as a foundation for:

- Experimenting with hierarchical data representations in generative models
- Testing adaptive diffusion over structured spaces
- Future extension to 3D octree-based models
